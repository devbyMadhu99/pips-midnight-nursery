# 🌙 Pip’s Midnight Nursery

*A little magical world of dreams, memories, and midnight wonder.* ✨

## 🚀 Live Demo

🌙 **Visit Website:** [Pip’s Midnight Nursery](https://pips-midnight-nursery-seven.vercel.app)

## 📖 About the Project

Pip’s Midnight Nursery is a dream-themed interactive website built with React. It creates a cozy, magical experience where users can generate dreams, save their favourite memories, explore a dream gallery, and enjoy interactive features inspired by the magic of nighttime.

## ✨ Features

- 🌙 **Dream Generator** — Generate magical dream stories.
- 📔 **Dream Journal** — Save and revisit dream memories.
- ❤️ **Favourite Dreams** — Mark dreams as favourites.
- 🗑️ **Delete Dreams** — Remove saved dreams from the journal.
- 🖼️ **Dream Gallery** — Explore dream-themed memories.
- 🌠 **Dream Streak** — Track dream-related activity.
- 🌌 **Interactive Experiences** — Explore magical features throughout the website.
- 💾 **Local Storage** — Keep saved dreams in the browser.
- 📱 **Responsive UI** — Enjoy the website on different screen sizes.

## 🛠️ Technologies Used

- **React.js** — Component-based user interface
- **Vite** — Development server and build tool
- **JavaScript (ES6+)** — Application logic
- **HTML5** — Page structure
- **CSS3** — Styling and responsive design
- **Browser localStorage** — Client-side dream persistence
- **Vercel** — Frontend deployment

## 💻 Getting Started

Follow these steps to run the frontend locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/devbyMadhu99/pips-midnight-nursery.git
   ```

2. Navigate to the frontend directory:

   ```bash
   cd pips-midnight-nursery/frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build for Production

To create an optimized frontend build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 💾 Data Storage

The dream journal uses browser `localStorage` to store saved dream entries. Data is associated with the current browser profile and is not automatically synchronized between devices or browsers.
